**DAPUR PANAS — Rush Hour Kitchen.** A fast-paced cooking game that runs offline in a desktop browser: you are the chef on a 3-minute dinner shift. Customers order from a 4-dish menu — Burger Klasik, Cheese Burger, Salad Segar, Double Stack — and walk out if they wait too long. Grab ingredients from the pantry, chop vegetables on the board, grill patties (rescue them before they burn!), build the plate on the assembly counter, and serve through the window before patience runs out. Three strikes end the shift early; serve fast for tips and a combo multiplier up to x2, and chase the 3-star shift.

Four recipes with real kitchen verbs (chop, grill, assemble, serve), a seeded mode (`?seed=N`) for reproducible runs, synthesized WebAudio sound effects with a mute toggle, and a best-coins total that persists between visits. Every sprite, sound and name is drawn and synthesized in code — no assets, no network requests.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Controls: WASD / arrows — walk · E — use a station · 1–5 / click — grab a pantry ingredient · click a station — use it · P — pause · M — mute · R — restart shift.
